Cek Status Pesanan

Masukkan Order ID untuk melihat progress, estimasi selesai, dan catatan admin.

Tips cepat
  • Copy Order ID dari halaman sukses / bukti pembayaran.
  • Kalau kamu baru saja order di device ini, klik Gunakan Order Terakhir.
  • Jika status belum berubah, tunggu beberapa menit lalu cek ulang.

Cari Pesanan

Contoh format Order ID: KS-123456

Hasil status akan tampil di bawah setelah kamu klik Cek Status.

Arti Status

PENDING
Pesanan masuk antrean.
PROCESS
Sedang diproses.
SUCCESS
Selesai / berhasil.
PARTIAL / REFUND
Sebagian selesai atau ada pengembalian.
Catatan: istilah status bisa berbeda tergantung provider layanan.
